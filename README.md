# 热搜连刷（hot-search-web）

机主自用「连刷」当日候选视频的纯静态页（连刷网页 v2，2026-10-06 拍板）。
GitHub Pages 托管（main 分支根目录），**只放链接与文本，全仓库零密钥**。

## 数据通道

```
本页（纯静态零密钥） → Cloudflare Worker 公开代理（hot-search-daily 仓 worker/） → TikHub
```

- 启动 `GET /api/state` 渲染当日批次计划（编号/批次/进度/日花费）；
- 从状态游标批续刷（与群「推N」/裸「推」共用同一游标）；
- 刷到第 7 条自动 `POST /api/batch` 预取下一批，手动「下一批」按钮做备胎；
- 批内按 Worker 回包顺序渲染（=揭示时现取真赞降序），编号与飞书卡片一一对应；
- 超界显示结束页「今日正推完，想继续到群里发『补』」；
- **网页没有补按钮、没有任何写操作**（摩擦即功能，防止无限刷）。

> 网页无图文区为拍板决策（永久，2026-10-06）：网页=纯视频连刷，图文照旧只在
> 飞书卡独立图文区看，Worker 不为网页加图文出口。批次内偶遇的图文帖仍正确渲染
> （🖼徽标+不出播放键+只走原帖）——渲染语义保留，板块不做。

## 暗号（拍板 e'）

暗号**禁止硬编码**进本仓库任何文件（公开仓库源码人人可读）。首次打开弹输入框，
用户手动粘贴暗号，存 `localStorage` 永久记住；之后每次请求带 `X-Hotsearch-Token` 头。
清浏览器数据/换浏览器/换设备才需重输。暗号值在 Cloudflare Worker 的
`WEB_PROXY_TOKEN`（Secret）里配置；真保险靠 Worker 侧日 $0.30 熔断 + 每批 ≤10 + 402 熔断。

## 配置（一次性）

`app.js` 顶部唯一常量 `WORKER_BASE` 改成你的 Worker 地址
（Cloudflare dashboard 可见，形如 `https://feishu-bot-worker.<子域>.workers.dev`）。
地址公开属正常——闸门是暗号与熔断，不是地址保密。

## 部署

**PR 合到 main 即生效**：Pages 已配置为 main 分支根目录，合并后约 1 分钟上线。
平时改动一律走分支 + PR，不直接推 main。

## 本地自验（零网络）

双击 `index.html`（file:// 打开即本地 mock 模式，或显式加 `?mock=1`）：
全走 `mock/fixture.js` 假数据（3 批 [10,10,3]、编号 1~23、批内真赞降序），
可完整走一遍：首次粘暗号（mock 模式任意输）→ 渲染第 1 批 → 刷到第 7 条自动预取
→ 手动「下一批」→ 第 3 批（末批 3 条）→ 再点「下一批」→ 结束页；
F5 刷新后暗号仍在、不重复弹框。
