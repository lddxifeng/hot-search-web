# 热搜连刷（hot-search-web）

机主自用「连刷」当日候选视频的纯静态页（连刷网页 v3.1「原帖接力连刷」，2026-10-07 拍板）。
GitHub Pages 托管（main 分支根目录），**只放链接与文本，全仓库零密钥**。

## v3.1 原帖接力连刷（当前形态）

本站只做「目录 + 接力导航」，视频流走抖音原帖页（永久免费、永不 403、原帖级清晰度）。
**不做**：沉浸式播放器、iframe（抖音 frame-ancestors 实测封死）、抓视频流地址
（临时链实测几分钟即烂）、播完自动跳转、下载视频本体、Worker /api/refresh（不需要）。

- **目录页**：全部已揭示批次按批分组（第 X 批 · #区间 · 现取真赞降序）；头部常驻
  当日计划/已刷到 #N/总条数/已揭示批数/日现取花费/换暗号；`document.title` 实时同步
  「#N/61 · 热搜连刷」。
- **原帖地址**（aweme_id 拼接，真机 A/B 选默认）：默认 `iesdouyin.com/share/video/{id}/`，
  头部可切换 `douyin.com/video/{id}`（存 localStorage）。
- **单看模式**（连刷关闭）：点条目跳该条原帖，返回后不自动跳。
- **连刷模式**：「▶ 开始连刷 / 继续 #N」同标签跳当前序号原帖 → 看完按浏览器返回 →
  目录页出后悔药倒计时横条「即将播放 #N+1」（2 秒进度条 + 「↺ 重看 #N」「⏸ 暂停连刷」）
  → 到点无操作自动接 #N+1；到已揭示末尾自动揭示下一批（转圈「解锁中」；Worker 状态文件
  刹车幂等防重）；手动「揭示下一批」按钮保留备胎；刷完出结束页，relay 自动关。
  「■ 停止连刷」常驻；F5/重开从 localStorage 恢复 relay 状态与进度。
- 返回检测只靠 localStorage 标记（`hs_pending`）+ pageshow，bfcache 与普通重载两路径同逻辑。
- **网页无图文区为永久拍板决策**（2026-10-06）：偶遇图文帖仍正确渲染（徽标+无播放键+原帖）。

## 数据通道

```
本页（纯静态零密钥） → Cloudflare Worker 公开代理（hot-search-daily 仓 worker/） → TikHub
```

- 启动 `GET /api/state` 读当日计划；每批明细走 `POST /api/batch`（已揭示=缓存零成本，
  未揭示=现取 $0.010/批，日 $0.30 熔断兜底）；
- **网页没有补按钮、没有任何写操作**（摩擦即功能，防止无限刷）。

## 暗号（拍板 e'）

暗号**禁止硬编码**进本仓库任何文件（公开仓库源码人人可读）。首次打开弹输入框，
用户手动粘贴暗号，存 `localStorage` 永久记住；之后每次请求带 `X-Hotsearch-Token` 头。
清浏览器数据/换浏览器/换设备才需重输。暗号值在 Cloudflare Worker 的
`WEB_PROXY_TOKEN`（Secret）里配置；真保险靠 Worker 侧日 $0.30 熔断 + 每批 ≤10 + 402 熔断。
