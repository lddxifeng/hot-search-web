# 热搜连刷（hot-search-web）

机主自用「连刷」当日候选视频的纯静态页（连刷网页 v4「去真赞化」，2026-10-07 拍板）。
GitHub Pages 托管（main 分支根目录），**只放链接与文本，全仓库零密钥**。

## v4.2 小改包（2026-10-07 拍板，当前形态）

- **继续=下一条**：暂停/停止后再点「开始连刷」，从 `cur+1` 起播，不再重播当前条；
  目录单看兜底不变（点标题/条目正文=单看，不写接力标记）。
- **从 #N 开始连刷**：每条编号 #N 可点——点编号=从该条起连刷（指针设为 N）；
  从头开始=点 #1 编号。
- **🔥热度·峰值**：四指标统一峰值口径（👍窗口赞·峰值 / 🔥热度·峰值 / ▶窗口播放·峰值 /
  赞播比·峰值；赞播比=Worker 透传 best_ratio）。
- **后悔药倒计时 2s→1s**：`RELAY_COUNTDOWN_MS=1000` 可调常量（真机太紧回 1500）。
- **发布时间**：四指标行加「发布·YYYY-MM-DD」（Worker 透传 pub_ts；缺省/0 隐藏）。

## v4 去真赞化（当前形态）

JIT 真赞揭示整体退役：网页不再调用 `/api/batch`，全站不出现「揭示/解锁/花费」概念。
当日全部计划条目（编号 #1~N + 标题/作者/时长/窗口播放/分享链接）通过 `/api/state`
一次读取全量展示；条目不显示赞/评/转/藏，只带池内免费四指标——👍窗口赞/🔥热度/
▶窗口播放/赞播比（best_*=历史最高窗口值，标「峰值」；赞播比=Worker 透传 best_ratio），
非零才显示。

- **目录页**：当日计划一次全出，每 10 条一个视觉分区（第 1 区 #1–#10…，纯视觉分区）；
  头部常驻当日计划总数/已刷到 #N/总数/换暗号/原帖域名切换；`document.title` 实时同步
  「#N/61 · 热搜连刷」。
- **原帖地址**（aweme_id 拼接，真机 A/B 选默认）：默认 `iesdouyin.com/share/video/{id}/`，
  头部可切换 `douyin.com/video/{id}`（存 localStorage）。
- **单看模式**（连刷关闭）：点条目跳该条原帖，返回后不自动跳。
- **连刷模式**（接力核心与 v3.1 一字不动）：「▶ 开始连刷 / 继续 #N」同标签跳当前序号
  原帖 → 看完按浏览器返回 → 后悔药倒计时横条「即将播放 #N+1」（2 秒进度条 +
  「↺ 重看 #N」「⏸ 暂停连刷」）→ 到点无操作自动接 #N+1；刷完结束页
  「今日 N 条全部刷完」，relay 自动关。「■ 停止连刷」常驻；F5/重开从 localStorage
  恢复 relay 状态与进度；跨天作废。
- 返回检测只靠 localStorage 标记（`hs_pending`）+ pageshow，bfcache 与普通重载两路径同逻辑。
- **网页无图文区为永久拍板决策**（2026-10-06）：偶遇图文帖仍正确渲染（徽标+只走原帖）。
- **不做**：沉浸式播放器、iframe、抓视频流地址、播完自动跳转、下载视频本体、
  补按钮、任何写操作。

## 数据通道

```
本页（纯静态零密钥） → Cloudflare Worker 公开代理（hot-search-daily 仓 worker/）
```

只有一个端点：`GET /api/state`（当日计划全量，含条目；读 data 分支批次状态文件，
零 TikHub 调用、零花费）。暗号鉴权（401 自动重弹框）。

## 暗号（拍板 e'）

暗号**禁止硬编码**进本仓库任何文件（公开仓库源码人人可读）。首次打开弹输入框，
用户手动粘贴暗号，存 `localStorage` 永久记住；之后每次请求带 `X-Hotsearch-Token` 头。
清浏览器数据/换浏览器/换设备才需重输。暗号值在 Cloudflare Worker 的
`WEB_PROXY_TOKEN`（Secret）里配置。

## 本地自验（零网络）

倒计时横条 → 自动接 #2 / 重看 #1 / 暂停 → 连到 #40 → 直接接 #41（全程无 /api/batch）
→ F5 显示「继续 #41」→ 停止连刷 → #61 后结束页「今日 61 条全部刷完」。
mock 专属测试钩子：`?setcur=N&relay=on` 预设进度；`?slow=1` 倒计时放慢；`?hold=1`
横条冻结（供点按钮验收）。
